# GitHub 與 Render 部署指南

## 專案入口與依賴

本專案是 Python Web 應用程式，以根目錄 `main.py` 啟動，不需要建置或發佈 Python 套件。Python 使用 3.14 系列，由 `.python-version` 與 `pyproject.toml` 一起限制。

- `pyproject.toml`：直接依賴，只有 FastAPI 與 Uvicorn。
- `uv.lock`：鎖定所有依賴的確切版本。
- `requirements.txt`：由鎖定檔匯出，供 Render 與 pip 安裝。
- MediaPipe JavaScript、WASM 與模型在瀏覽器下載，不加入 Python 套件清單。

更新依賴後必須重新匯出，再一併提交以上三個檔案：

```powershell
uv lock
uv sync --locked
uv export --locked --no-dev --no-emit-project --no-hashes --output-file requirements.txt
```

## 上傳 GitHub

根目錄包含應用程式、靜態檔案、測試、部署設定與文件。`.venv`、`.qa`、快取、`.env` 及本機認證目錄均由 `.gitignore` 排除。

首次建立 GitHub 儲存庫時，請先建立空白儲存庫，不要另外初始化 README、授權或 `.gitignore`，再將本機專案推送。已有其他內容的遠端儲存庫，應先取得歷史並整合，避免覆蓋。

```powershell
git branch -M main
git remote add origin https://github.com/OWNER/REPOSITORY.git
git push -u origin main
```

上述 `OWNER/REPOSITORY` 請換成實際儲存庫，且本機必須先完成 GitHub 登入與 Git 提交。若已設定 `origin`，先以 `git remote -v` 確認目的地。

專案提供 `.github/workflows/ci.yml`，在推送或 Pull Request 時檢查鎖定檔、requirements 匯出一致性、Python 相依性、HTTP 路由，以及所有手勢與圖片邏輯測試。Node.js 只供測試使用，Render 不需要安裝 Node.js 或執行 npm 建置。

## Render 設定

登入 Render，建立 Blueprint 並連接 GitHub 儲存庫，選取包含 `render.yaml` 的分支。也可手動建立 Web Service，使用下列設定：

| 欄位 | 設定 |
| --- | --- |
| Runtime | Python |
| Branch | `main`，或實際推送的分支 |
| Root Directory | 儲存庫根目錄，留白 |
| Python | `.python-version` 指定的 3.14 系列 |
| Plan | Free，升級時再調整 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn main:app --host 0.0.0.0 --port $PORT` |
| Health Check Path | `/health` |
| Environment | `PYTHONUNBUFFERED=1` |

應用程式不需要 API 金鑰、資料庫或持久化磁碟。瀏覽器端的使用者圖片與攝影機內容不會上傳。服務啟動命令使用 Render 提供的 `$PORT`，本機 Windows 仍使用 `uv run --frozen python main.py`。

## 部署後驗收

1. 檢查 GitHub Actions 與 Render 建置／啟動紀錄。
2. 開啟正式 HTTPS 網址，首頁應轉至 `/static/index.html`，版面與範例圖片正常載入。
3. 請求 `/health`，確認回傳 `{"status":"ok"}`。
4. 按「開啟攝影機」，允許新網域的權限，確認 MediaPipe、WASM 與模型下載成功。
5. 依 [驗收清單](驗收清單.md) 實測換圖、雙手翻面、握拳、縮放與旋轉。

健康檢查與自動測試無法取代真實攝影機驗收。Render 網域、瀏覽器權限及外部 CDN 可用性需在正式網址確認。
