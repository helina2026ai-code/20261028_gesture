# 手勢圖片播放器操作指南

## 啟動

在專案根目錄執行 `uv sync --frozen`，再執行 `uv run --frozen python main.py`。開啟 <http://localhost:8000>。不開啟攝影機也能使用右側圖片按鈕。

Windows 也可雙擊根目錄的 `啟動專案.cmd`，並保持出現的終端機視窗開啟。首頁會自動轉到 `/static/index.html`，以確保圖片、樣式與程式都從正確位置載入。

### 畫面沒有樣式，按鈕沒有反應

這通常代表 CSS 與 JavaScript 沒有載入。請使用上方啟動方式，並在 Chrome 或 Edge 輸入 <http://localhost:8000>。直接雙擊 `static/index.html` 會使用 `file://`，JavaScript 模組無法正常載入；頁面會顯示啟動提示。

本專案也支援 Live Server 從專案根目錄開啟 `/static/index.html`，或直接以 `static` 作為網站根目錄。攝影機網址需使用 localhost／127.0.0.1 或 HTTPS；以其他電腦的區域網路 HTTP 位址存取時可能無法取得權限。

### 樣式正常，但攝影機仍無法使用

按下「開啟攝影機」後查看狀態訊息。若權限遭拒，請在網址列的網站設定中允許攝影機；若被佔用，請關閉使用攝影機的其他程式。Windows 也需允許桌面應用程式存取攝影機。若停在載入模型或顯示下載失敗，請確認能連線至 jsDelivr 與 Google 模型儲存空間。

## 版面

- 左側：攝影機鏡像預覽、手部骨架、啟動／停止、辨識狀態，以及換圖、翻面、握拳、縮放與旋轉說明。
- 右側：圖片展示、名稱、頁碼、換圖、翻轉、縮放、旋轉及還原控制、本機圖片選擇與返回範例。
- 窄螢幕會改為上下排列：攝影機在上，圖片在下。

## 手勢控制

1. 按「開啟攝影機」，首次需下載模型，並在瀏覽器允許攝影機權限。載入中仍可按「停止偵測」取消。
2. 使用一隻手，讓手掌完整入鏡。避免側面、遮擋、逆光及過遠的手部。
3. 張開手掌，沿鏡像預覽畫面向左移一段距離，切換至上一張；向右移則切換至下一張。手掌需保持張開，並以水平移動為主。
4. 只伸出食指，另外三指彎曲，停留約半秒，跳到第一張；只伸出小指則跳到最後一張。拇指可自然放置。
5. 每次手勢觸發後約 0.9 秒才接受下一次。食指或小指持續不動不會重複觸發，需先收回約 0.2 秒再重新比出。
6. 第一張無法再往前，最後一張無法再往後，畫面會提示已達邊界。
7. 按「停止偵測」釋放攝影機；圖片仍可操作。切換到背景分頁也會停止偵測，回到頁面後請重新啟動。

偵測到兩隻手時保留翻面控制，四種換圖手勢仍使用單手，以避免不同手之間的移動軌跡混在一起。初始判定參數需要依真實攝影機測試調整，並非所有光線、角度或手形都能準確辨識。

## 雙手與翻面互動

1. 開啟攝影機，張開一隻或兩隻手，先穩定朝向鏡頭約半秒，讓程式建立每隻手的朝向基準。
2. 保持手指張開，將其中一隻手從手心翻到手背，或從手背翻回手心；讓新的一面朝向鏡頭並穩定約 0.2 秒。
3. 目前圖片會以水平翻轉動畫切換至左右鏡像；再翻一次手，就會還原。右側「目前」文字顯示圖片方向。
4. 左手、右手都可操作；雙手同時翻面只觸發一次。每次翻面後請停頓約 0.9 秒，持續維持同一面不會重複觸發。
5. 雙手請稍微分開，避免交疊；手離開畫面過久、追蹤中斷、手掌交疊或手部位置突然跳動時會重新建立基準，首次重新入鏡不會立即翻圖。
6. 換圖、食指／小指操作、四個原有按鈕及鍵盤都維持原有功能。翻手過程會暫停換圖判定，完成後稍作停頓即可繼續。

也可直接按右側「左右翻轉」按鈕，按鈕會顯示目前是否為鏡像。每張圖片各自記住方向，切回同一張時保留；更換本機圖片或返回整組範例時重設為原始方向。只對圖片套用翻轉，文字、頁碼及攝影機預覽不受影響。

## 單手握拳互動

1. 畫面中只保留一隻手，先張開手掌停留約半秒。
2. 將手掌握成拳，保持約半秒，讓模型穩定辨識握拳。
3. 目前圖片會上下鏡像翻轉；持續握拳不會反覆觸發。
4. 等待約 0.9 秒冷卻後，先重新張開手掌，再握拳，即可還原上下方向。
5. 初始直接以拳頭入鏡、同時出現兩隻手、低信心結果或追蹤中斷時，需要重新張開再握拳。模型使用 `Closed_Fist` 分類，避免把比讚當成握拳。

右側「上下翻轉」按鈕也能執行同一效果。上下、左右鏡像互相獨立：兩者可同時套用，取消其中一個不影響另一個。每張圖片都分別記住兩個方向，更換整組圖片後才重設。

## 雙手縮放與旋轉

1. 兩隻手張開，稍微分開並停留約半秒，讓程式建立雙手位置基準。
2. 將雙手向左右拉開，圖片會放大；向內靠近則縮小。範圍為 100%–300%。
3. 將雙手調整為一高一低，圖片會依照兩手的連線角度旋轉。以左側鏡像預覽為準：畫面右側手較低時順時針轉，較高時逆時針轉。
4. 水平距離控制大小、高低差控制角度，可同時操作。輕微抖動不會立即改變圖片，動作會平滑顯示。
5. 放下手後保留目前大小與角度。重新放入兩隻張開的手，會以當時位置及圖片狀態重新建立基準，避免跳動。
6. 手心／手背翻面優先處理，翻面後稍停再繼續縮放或旋轉。只有一隻手、雙手太靠近、交叉、握拳或追蹤中斷時，暫停雙手縮放／旋轉。

也可使用右側放大／縮小按鈕，每次調整 25 個百分點；左轉／右轉按鈕每次調整 15°。「還原大小／角度」回到 100%、0°，保留左右／上下鏡像。每張圖片各自記住大小與角度，更換整組圖片後重設。

圖片以展示框中心縮放與旋轉，超出框的部分會裁切，標題、張數及控制按鈕維持正常方向。

## 按鈕與鍵盤

| 動作 | 按鈕 | 鍵盤 |
| --- | --- | --- |
| 第一張 | 第一張 | Home |
| 上一張 | 上一張 | ← |
| 下一張 | 下一張 | → |
| 最後一張 | 最後一張 | End |
| 圖片水平鏡像／還原 | 左右翻轉 | — |
| 圖片上下鏡像／還原 | 上下翻轉 | — |
| 圖片大小 | 放大／縮小 | — |
| 圖片角度 | 左轉／右轉 | — |
| 回復 100%、0° | 還原大小／角度 | — |

也可點選圖片下方圓點，直接跳到指定圖片。手動操作會暫停手勢控制約 0.9 秒，避免按下按鈕後立刻被尚未結束的手勢切回。

## 使用自己的圖片

按「選擇圖片」，可多選 JPG、PNG、WebP、GIF 或 AVIF。圖片依檔名排序，數字採自然排序，例如 `1.jpg`、`2.jpg`、`10.jpg`。圖片格式須由使用的瀏覽器支援；副檔名與實際格式不符或損壞時，會顯示無法載入的提示。

本機圖片僅存在這次瀏覽器工作階段，不會上傳至 Render。按「返回範例圖片」可還原；重新整理頁面也會還原。選圖視窗取消或僅選到不支援的檔案，會保留目前圖片。

若要永久更換內建圖片，把檔案放入 `static/images/`，並編輯 `static/gallery.mjs` 的 `SAMPLE_SLIDES`，每筆資料提供 `src`、`title`、`description`。預設首頁也有第一張的靜態預覽，可同步更新 `static/index.html`；JavaScript 啟動後會以清單為準。

## 開發參數

`static/gesture-controller.mjs` 的 `GestureController` 提供下列預設值：

| 參數 | 預設值 | 說明 |
| --- | --- | --- |
| holdMs | 450 ms | 食指／小指需保持的時間 |
| releaseMs | 200 ms | 收回手指後重新允許觸發的時間 |
| cooldownMs | 900 ms | 手勢觸發及手動操作後的冷卻時間 |
| swipeDistance | 0.17 | 水平移動需超過畫面寬度 17% |
| swipeWindowMs | 650 ms | 掌心軌跡觀察時間窗 |
| minSwipeMs | 130 ms | 防止極短跳動被當成移動 |
| maxVerticalDrift | 0.12 | 軌跡垂直範圍上限，畫面高度 12% |

改值後執行 `node --test tests/gesture-controller.test.mjs`，並重新進行攝影機實測。

`static/hand-flip-controller.mjs` 的翻面判定預設使用 200 ms 穩定時間、900 ms 冷卻、250 ms 追蹤間隔上限及 1800 ms 翻面時間窗。以手腕、食指根部與小指根部的 3D 座標計算掌面法向量，追蹤每隻手的方向變化。使用掌心位置配對，不依賴模型陣列順序或翻面時可能變動的左右手標籤。測試換圖與翻面邏輯可執行 `node --test tests/gesture-controller.test.mjs tests/hand-flip.test.mjs`。

`static/fist-controller.mjs` 預設張開確認 200 ms、握拳確認 450 ms、冷卻 900 ms、分類信心門檻 0.65、追蹤間隔上限 250 ms。加入握拳測試的完整指令為 `node --test tests/gesture-controller.test.mjs tests/hand-flip.test.mjs tests/fist-controller.test.mjs`。

`static/two-hand-controller.mjs` 預設基準建立 200 ms、追蹤間隔上限 250 ms、水平最小間隔為畫面寬度 16%、縮放死區 6%、角度死區 6°，平滑係數 0.35。角度計算會依攝影機寬高比校正，採畫面位置排序，不依模型輸出順序。測試全部功能可執行 `node --test tests/gesture-controller.test.mjs tests/hand-flip.test.mjs tests/fist-controller.test.mjs tests/two-hand-controller.test.mjs`。

## Render

沿用根目錄 `render.yaml`：建置執行 `pip install -r requirements.txt`，啟動執行 `uvicorn main:app --host 0.0.0.0 --port $PORT`，健康檢查 `/health`。上線後請從 HTTPS 網址開啟並重新授權攝影機。
