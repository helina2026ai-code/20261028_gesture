# 手勢圖片播放器驗收清單

以下項目需在有攝影機的瀏覽器實測，勾選前請記錄瀏覽器、裝置、日期及結果。自動邏輯測試不代表已完成實機驗收。

## 版面與圖片

- [ ] 桌面左側為攝影機，右側為圖片；窄螢幕改為上下排列，沒有水平溢出。
- [ ] 初始顯示第一張，共五張，標題與頁碼一致。
- [ ] 四個按鈕、鍵盤 ←／→／Home／End、頁碼圓點皆可正確切圖。
- [ ] 第一張的「第一張／上一張」按鈕停用；最後一張的「下一張／最後一張」停用，不循環。
- [ ] 單張本機圖片的四個按鈕皆停用；手勢不會造成錯誤。
- [ ] 多選本機圖片依檔名自然排序；取消選取保留目前圖片。
- [ ] 替換本機圖片、返回範例、重新整理後的圖片狀態符合操作指南。
- [ ] 損壞或瀏覽器不支援的圖片有載入失敗提示，仍可換圖。

## 攝影機生命週期

- [ ] 允許權限後顯示鏡像畫面與對齊的手部骨架。
- [ ] 拒絕權限、無攝影機、攝影機被佔用時有清楚提示，仍可用按鈕切圖。
- [ ] 模型 CDN 或模型下載失敗時可重試，右側圖片不受影響。
- [ ] 載入模型中按停止，不會在模型載完後自動開啟攝影機。
- [ ] 等待授權時按停止，之後即使授權也不會重新啟動；取得的串流會被釋放。
- [ ] 停止、切換至背景分頁、離開頁面後，攝影機停止使用。
- [ ] 多次啟動／停止可恢復辨識，不會累積多個畫面更新迴圈。

## 手勢與干擾

- [ ] 張開手掌沿鏡像畫面向左移，切換上一張；向右移，切換下一張。
- [ ] 只伸出食指約半秒跳到第一張；只伸出小指約半秒跳到最後一張。
- [ ] 握拳只切換上下鏡像方向，不更換圖片張數；勝利手勢及其他非指定姿勢不換圖。
- [ ] 食指／小指持續不動只觸發一次，收回後重新比出才再次觸發。
- [ ] 小幅抖動、緩慢漂移、主要向上／向下移動不切圖。
- [ ] 兩次操作間有約 0.9 秒冷卻；返回手掌原位時不會立即反向切圖。
- [ ] 手部離開後重新入鏡，不把跨空白期間的位置差當成滑動。
- [ ] 兩隻手入鏡時仍能翻面，四種換圖操作維持單手。
- [ ] 左手、右手、不同光線、相機距離與常見手掌傾斜角度皆完成測試並記錄失敗情境。

## 翻面與鏡像

- [ ] 手心翻至手背、手背翻回手心，都使目前圖片水平鏡像切換一次。
- [ ] 左手、右手與雙手入鏡皆可操作，雙手同時或略有時間差翻面不會連續翻兩次互相抵銷。
- [ ] 保持同一面不反覆翻圖，輕微側轉與抖動不觸發；翻手不會同時換圖。
- [ ] 雙手交疊、突然移位、長時間離開再入鏡，不會誤翻圖片。
- [ ] 「左右翻轉」按鈕可操作，只有圖片變換方向，文字與頁碼正常。
- [ ] 換到其他圖片時使用該圖片的方向，再切回時保留原設定；更換整組圖片後回復原始方向。
- [ ] 手機版面沒有水平溢出；系統啟用減少動態效果時不播放翻轉動畫。

## 單手握拳與上下鏡像

- [ ] 單手先張開、再握拳約半秒，目前圖片上下鏡像翻轉。
- [ ] 持續握拳不重複觸發；冷卻後重新張開再握拳可還原。
- [ ] 起始直接握拳、雙手握拳、比讚、短暫握拳或低信心結果不誤觸發。
- [ ] 手離開、追蹤中斷或停止／重新啟動攝影機後，須重新張開再握拳。
- [ ] 「上下翻轉」按鈕可操作；上下及左右鏡像能獨立組合、取消。
- [ ] 換圖後回來仍保留兩個方向；換整組圖片後皆重設。
- [ ] 單手換圖、雙手翻面、鍵盤、圖片選擇與原有按鈕功能正常。

## 雙手縮放與旋轉

- [ ] 雙手張開稍停建立基準，初次入鏡不改變圖片大小或角度。
- [ ] 雙手水平拉開放大、靠近縮小，限制在 100%–300%。
- [ ] 雙手一高一低可旋轉，鏡像畫面右側手較低時順時針、較高時逆時針。
- [ ] 純水平移動不旋轉，固定水平距離只改高低時不縮放；小幅抖動不誤操作。
- [ ] 放下手保留結果；重新入鏡、雙手交叉或追蹤中斷後不突然跳動。
- [ ] 雙手翻面仍可左右翻轉，單手握拳仍可上下翻轉，原有換圖手勢正常。
- [ ] 放大／縮小、左右旋轉及還原按鈕可用，狀態文字與圖片一致。
- [ ] 每張圖片記住自己的大小、角度及鏡像；還原大小／角度保留鏡像；換整組圖片全部重設。
- [ ] 圖片轉換只影響圖片，文字與頁碼正常；桌面與手機版面沒有水平溢出。

## 部署

- [ ] Render 建置及啟動成功，`/health` 回傳 `{"status":"ok"}`。
- [ ] 正式 HTTPS 網址能載入所有圖片、JavaScript、WASM 與模型。
- [ ] 正式網域重新授權攝影機後可操作，並完成桌面及行動裝置測試。
